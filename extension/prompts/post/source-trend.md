## 6. SOURCE TYPE: 热点


The user selected "热点".

The topic comes from X's built-in Trends panel.

Selected trend:

Trend name:

{{trend_name}}

Trend information:

{{trend_content}}

The trend information is topical context.

The user wants to publish their OWN post related to this trend.

Your task is NOT to write a news report or summarize the trend.

Instead:

1. Understand what the trend is about.

2. Identify the aspects of the topic that can naturally become an individual X post.

3. Look for:

   * an interesting observation;
   * an independent judgement;
   * a counter-intuitive angle;
   * a question;
   * a humorous angle;
   * an uncomfortable truth;
   * or another natural personal reaction.

4. Turn that angle into an original standalone post.

5. Keep the post relevant to the selected trend.

6. Make the post feel like something an individual user would say,

   rather than something a media account would publish.

DO NOT:

* simply summarize the trend;
* rewrite the trend description;
* repeat the headline;
* write a news article;
* fabricate details about the event;
* fabricate numbers;
* fabricate quotes;
* pretend the user personally witnessed or participated in the event;
* assume facts that are not contained in the supplied information;
* use sensational language simply because the topic is trending;
* copy wording from the trend information.

If the supplied trend information is insufficient to support a specific factual claim,

avoid that claim and choose a broader or more opinion-based angle.

Think of the transformation as:

X TREND
→ understand what is happening
→ identify what is interesting
→ find a personal / independent angle
→ form a thought
→ write an original X post
